## Executive Summary
The **Local Public Market Stall Management System** is a Java console application engineered to modernize municipal public market administration. By replacing error-prone paper logbooks with an Object-Oriented desktop system backed by local CSV persistence, market administrators and staff can accurately track vendor profiles, prevent stall double-bookings, calculate polymorphic stall rental rates, issue text receipts, monitor expiring permits, and export treasury reports offline.
